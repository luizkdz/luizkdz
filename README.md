# 🚀 Projetos em destaque

## ✈️ SkyPass — Sistema de Passagens Aéreas

Um dos meus principais projetos Full Stack.

O **SkyPass** é uma aplicação de compra de passagens aéreas inspirada em plataformas de viagens, desenvolvida com React no frontend e Node.js + TypeScript no backend.

O projeto possui funcionalidades como:

* 🔎 Busca e filtragem de voos
* ✈️ Seleção de voos de ida e volta
* 👤 Autenticação de usuários
* 🔐 JWT e controle de acesso
* 👥 Cadastro de passageiros
* 💺 Seleção de assentos
* 💳 Pagamentos com Stripe
* 💰 Cadastro e gerenciamento de cartões
* 📦 Criação e gerenciamento de reservas
* 📧 Cadastro de usuários
* 🔗 Integração entre frontend e API REST
* 🧪 Testes automatizados
* 🗄️ Persistência com MySQL

### Backend

O backend foi estruturado utilizando uma separação entre responsabilidades, incluindo:

```text
src/
├── controllers/
├── repositories/
├── routes/
├── middlewares/
├── database/
└── ...
```

A API utiliza **Node.js, TypeScript, Express, MySQL, JWT, bcrypt e Stripe**, além de testes com Jest e Supertest.

### Frontend

O frontend utiliza **React + TypeScript + Vite**, com formulários, rotas, filtros de busca, checkout e integração com Stripe.
